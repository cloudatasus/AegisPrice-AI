# 🛡️ AegisPrice AI

## 基於 Multi-Agent 壓力測試的實體產業「自適應決策大腦」

> 大賽參賽企劃書 — 以「洋芋片（FMCG 快消品）」作為降維打擊的試金石，完美融合 55% 實用價值、20% 商業計畫、15% 技術實現與 10% 資訊安全的評分權重。

---

## 一、項目摘要 (Abstract)

傳統實體產業長期面臨「上游成本變動大、現在銷售通路多維、未來產品迭代快」的結構性痛點，跨部門資訊孤島導致決策滯後、毛利流失。

本項目推出 **AegisPrice AI**，這是一套專為企業高階決策層（C-Suite）設計的 AI 商業戰略副駕駛（Copilot）。系統採用 **LangGraph 多智能體（Multi-Agent）圖架構**，打破傳統 AI「自動改價」帶來的合規與通路衝突風險，改以「**智能推演 ➡️ 策略推薦 ➡️ 人類審查（Human-in-the-Loop）**」的嚴謹流程落地。

我們以人人皆知的「洋芋片（民生快消品）」作為原型驗證（PoC），展示系統如何從「棕櫚油暴漲（上游）」推演出「D2C 官網閃卡綑綁包（現在）」，並反向定義出「不沾手玩家碎星洋芋片（未來）」的商業全閉環。本系統之底層框架具備極高規模化（Scale）潛力，能無縫複製至智慧汽車、消費性電子與醫療器材等數兆美元規模之實體產業。

## 二、實用價值分析 (55%)：直擊行業痛點與創造爽點

### 1. 行業痛點（痛在哪）

- **成本與售價脫鉤**：上游原料（如棕櫚油、馬鈴薯、包材）價格日頻變動，但實體通路（如超商、量販店）的標價合約多為死板長約，傳統財務核算滯後，導致企業往往在「毛利已破防」數週後才有所察覺。
- **通路衝突與品牌貶值**：面對市場銷量下滑，傳統流程僅能進行粗暴的線上線下「流血打折」，這不僅引發線下經銷商抗議（違反 MSRP 協定），更會破壞消費者心中的價格錨定，造成品牌貶值（Price Erosion）。
- **研發與市場脫節**：快消品或硬體生命週期短、迭代極快。研發部門（R&D）往往憑空想像新品口味或規格，導致高達 80% 的新產品上架不到一季便因滯銷而報廢，造成巨大浪費。

### 2. 系統創造的核心價值（爽點在哪）

- **精準利潤防禦（省時、省力）**：省下跨部門拉報表、重新核算 BOM 成本的時間，系統在分鐘級內自動感知上游成本波動，守住企業利潤底線。
- **隱蔽式價值極大化（少麻煩）**：不改動硬體/商品官方售價，改由 AI 自主規劃「實物商品 ＋ 限量周邊 ＋ 軟體/商城訂閱服務」的差異化綑綁包（Bundle），用零邊際成本的服務吸收上游成本衝擊，免去通路衝突的麻煩。
- **反向工程指導研發（明顯改善）**：終結研發盲目摸索。系統從「定價壓力測試失敗」的異常數據中進行反思，精準挖掘出市場真空帶，讓新品出廠即爆款。

## 三、技術實現與工具運用 (15%)：真正的 Agentic AI 展現

本作品絕非單純呼叫大模型進行文本輸入輸出，而是利用 **LangGraph** 開發框架，建構出具備「自主拆解、工具調用、自我反思」能力的 Multi-Agent 閉環網絡：

```
                ┌────────────────────────────────┐
                │ 1. 溯源成本聯動分析 Agent      │
                │    (監控上游原料/包材成本)      │
                └───────────────┬────────────────┘
                                │
                                ▼
┌──────────────────────────┐ 協同對話 ┌──────────────────────────┐
│ 3. 反向預測與產品定義    │◄────────►│ 2. 即時價值極大化引擎    │
│    Agent                 │          │    Agent                 │
│    (輿情爬蟲 RAG/新品PRD)│          │    (多通路促銷/API調用)  │
└──────────────────────────┘          └──────────────────────────┘
```

### 1. 三大代理模組運行流程

#### 🔹 昨日成本：溯源成本聯動分析 (Upstream Cost Linked Analytics)

**Agent 代理行為**：主動調用內部 ERP 資料庫與外部期貨 API，監控棕櫚油與馬鈴薯成本。當計算出綜合毛利低於 15% 時，主動發出熔斷預警，禁止前端直接降價，並將狀態移交給下一決策棒次。

#### 🔹 今日變現：即時價值極大化引擎 (Real-Time Value Maximization Engine)

**Agent 代理行為**：評估當前電商流量與購物車未結帳率。在不驚動線下通路的原則下，主動規劃出「買 $590 洋芋片箱，搭贈限量動漫閃卡與 3 個月商城免運會員」的隱蔽式方案，並將方案推播至 C-Suite 控制台，等待人類審查。

#### 🔹 明日創新：反向預測與產品定義 (Reverse Forecasting & Product Definition)

**Agent 代理行為**：針對銷量低迷的定價壓力測試進行自我反思（Reflection）。自主調用 Web 爬蟲工具，前往 Threads、Dcard 抓取 6,000 則有關零食的負評文本，透過 RAG 語意分析發現「玩遊戲吃洋芋片手會油」的痛點，進而反向自動生成一份「不沾手 Gamer 碎星洋芋片（定價 $69）」的新產品需求文件（PRD）。

### 2. 工具調用 (Tool Use)

| 端 | 工具 |
|----|------|
| 數據端 | 透過 SQL-Agent 自主查詢企業內部 ERP 與 BOM 成本 |
| 執行端 | 核准後，自動調用 Shopify API 上架組合包、呼叫 Omnisend API 發送定向行銷郵件 |

## 四、商業計畫與推廣路徑 (20%)

### 1. 目標使用者 (Target Users)

中大型 FMCG 集團、品牌商、消費性電子廠的 **CMO（行銷長）**、**CPO（產品長）** 與電商營運總監。

### 2. 商業模式 (Revenue Model)

| 階段 | 模式 |
|------|------|
| 第一階段（標準 SaaS） | 提供標準系統 API 插件，每月收取固定系統訂閱費 |
| 第二階段（超額利潤分潤） | 針對系統帶來的超額利潤收取 3%~5% 技術分潤 |

### 3. 規模化擴展性 (Scalability)

洋芋片（FMCG）只是概念驗證。本系統的核心架構完全適用於任何「高精密度、快速迭代」的實體產業：

> **規模化至電動車產業**：棕櫚油 → 鋰電池、動漫閃卡 → 自動駕駛 SaaS 服務、不沾手洋芋片 → 銀髮守護電動車款。

## 五、資訊安全與風險防範 (10%)

企業戰略數據涉及商業機密，本系統設計了三道硬性防線：

1. **完全本地化部署支持 (100% Local Deployment)**
   - 系統支持開源庫運行，可對接企業內部私有化大模型（如微調後的 Llama 3）
   - 核心財務數據與 BOM 成本完全不需上雲，徹底杜絕洩密風險

2. **安全硬熔斷與權限控管 (Guardrails & RBAC)**
   - 代碼底層寫死硬性規則，任何 Agent 生成之方案，其利潤絕對不得低於成本底線
   - 嚴格執行基於角色的權限控管（如 Hunter Agent 僅有讀取權，絕無修改價格之權限）

3. **提示詞注入防禦 (Prompt Injection Defense)**
   - 在 Agent 輸入端架設 Llama Guard 護欄
   - 防止惡意消費者透過修改前端購物車或惡意評論來刻意誘導定價 Agent 進行資產賤賣
