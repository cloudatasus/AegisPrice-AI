MCP — Model Context Protocol

採最新大模型開放標準，將數據源與工具徹底解耦。成本計算走 100% 結構化 SQL，杜絕 LLM 幻覺。核准後自動調用 Shopify API 上架、Omnisend API 推播。

RAG — 雙重向量記憶機制

Human-in-the-Loop

所有 Agent 方案僅為「推薦」，必須經主管核准才會執行部署。利潤底線寫死硬熔斷，Agent 僅有讀取權，無修改價格權限。

100% 本地化部署

支援對接私有 Llama 3，商業機密完全不上雲。輸入端架設 Llama Guard 護欄，防禦 Prompt Injection 攻擊。

企業級防禦防線

系統讀取供應鏈成本、ERP 庫存與消費者數據——資安設計是能否落地的關鍵。

🔒
資料保護與敏感隔離
  • 去識別化：PII（姓名/Email/卡號）在本地端以 Hashing/Masking 過濾後才送入 LLM
  • 企業級 API：使用 Azure OpenAI / AWS Bedrock，數據不會被用於微調公共模型
  • 商業機密：完全不上公共雲，支援 100% On-Premise 部署
🛑
權限控管與熔斷機制
  • RBAC：Hunter Agent 唯讀，無法修改價格
  • Guardrails：定價 ≥ BOM × 105%，違反自動攔截
  • Human-in-the-Loop：變動 >30% → 暫停 → Slack/Teams 等主管 Approve
🧱
防範 Agent 暴走
  • Prompt Injection 防禦：輸入端架設 Llama Guard 護欄
  • 防惡意操控：阻止消費者透過購物車竄改或惡意評論誘導 Agent 賤賣
  • 異常行為偵測：Agent 輸出若偏離歷史決策分佈則自動凍結

📐 實務部署：雙頻策略架構

PoC 展示為加速演示採用即時觸發。實務部署採用雙頻策略：市場信號層（即時）提供 Early Warning 預警通知；成本決策層（月/季）對接企業 BOM 結算週期，產出戰略成本修正建議。兩層協作確保既不漏接黑天鵝事件，又貼合企業實際財務節奏。

❌ BOM 非即時，長約鎖價

期貨暴漲 ≠ 實質成本漲，多數企業已簽半年長約。

✅ 雙頻策略

即時層 Early Warning，月/季層對接 BOM 修正。

❌ ERP 系統孤島

SAP 舊版複雜，資料清洗成本高於短期利潤。

✅ 輕量對接

Phase 1 用 Excel（合約到期日+鎖價），後續漸進整合。

❌ 綑綁包無法全自動

庫存備料、包裝設計、通路合約審查仍需人工。

✅ AI 推薦 + 人工落地

策略推薦引擎，自動化限縮 D2C 可控通路。

❌ 新品 PRD 難直接採用
